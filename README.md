### ✨ 系統主要功能特色
* **智慧排序**：支援依「店碼」及「縣市」雙向排序（遞增/遞減/還原）。
* **多元篩選**：提供關鍵字即時搜尋、縣市分類篩選、廣告類型篩選（帆布外招/導光板/包柱/大圖輸出）、以及「僅顯示新增門市」。
* **完整圖資分類**：
  1. **門市外觀（原本照片）**：完整還原原始 PPT 簡報之紅色 A/B/C 定位標籤。
  2. **廣告海報（視覺設計圖）**：廣告海報、設計稿及平面尺寸圖。
  3. **2026現況（現況照片）**：2026 年最新外招現況實景。
  4. **定位截圖（Google地圖）**：門市地理位置與街景定位截圖。
* **高畫質燈箱放大**：點擊任一圖片皆可開啟高清檢視視窗。
* **標題凍結與便利滾動**：表格表頭垂直置頂凍結，底部水平滑桿常駐，方便跨欄位對照。
